# ActiveDesk

App de escritorio desarrollada en Python (PyQt6) diseñada específicamente para combatir el sedentarismo durante jornadas largas de programación.

## Características
- **Interfaz SPA (Single Page Application):** Todo ocurre en una misma ventana limpia.
- **Temporizador Dinámico:** Alertas configurables (15, 30, 45, 60 minutos).
- **Sistema Inteligente:** Recomienda ejercicios basándose en contexto y evita repetir grupos musculares.
- **Persistencia Local:** Guarda el progreso diario automáticamente.
- **Estilo Nativo Oscuro:** Interfaz optimizada (QSS) amigable a la vista.

## Instalación
1. Clona el repositorio.
2. Crea un entorno virtual: `python -m venv venv`
3. Instala dependencias: `pip install PyQt6`
4. Ejecuta: `python main.py`
